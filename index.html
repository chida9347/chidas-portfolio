Deep learning · Computer vision

Video-Based Deep Learning for Assessing Collaborative Learning Quality

A deep-learning system that analyses student interactions during collaborative learning activities using classroom video, and classifies group engagement as Low, Medium or High.

Problem addressed

Judging the quality of group collaboration from classroom recordings is slow and subjective when done by hand. This project explores automating engagement assessment from video.

Key features

  • Video preprocessing and frame extraction, with image resizing and normalization
  • CNN-based visual feature extraction and temporal sequence learning
  • Comparison of CNN+LSTM, CNN+GRU and CNN+SimpleRNN architectures against a MobileNetV2 baseline
  • Group engagement classification (Low / Medium / High) with temporal behaviour analysis
  • Group engagement trajectory visualization, model comparison and error analysis
PythonDeep LearningComputer VisionCNNLSTMGRUMobileNetV2Streamlit

Scope & limitation: The OUC-CGE dataset provides three engagement labels (Low, Medium, High). The system does not identify individual behaviours or predict student learning gains.

Machine learning · Data analysis

Prediction of Autism-Related Behavioral Risk Indicators Using Questionnaire Data

A machine-learning project that analyses questionnaire-based data to identify autism-related behavioral risk indicators.

Problem addressed

Screening questionnaires produce structured data that can be studied statistically. This project examines how well simple, interpretable models can pick out risk-related patterns in that data.

Key features

  • Dataset preprocessing and cleaning, including missing-value handling
  • Exploratory data analysis, feature selection and preparation
  • Logistic Regression classification with model evaluation

Security · Web · Hackathon

Graphical Password Authentication

A graphical-password authentication system built during the KALAM 2K26 hackathon. Users log in by selecting a sequence of images instead of typing a password.

Problem addressed

Text passwords are often weak or reused, and are exposed to brute-force and shoulder-surfing attacks. This project explores an image-based alternative with additional verification layers.

Key features

  • Graphical password registration and login by image sequence
  • OTP verification as a second authentication step
  • Dashboard that records login attempts
  • Dynamic image distortion (shuffle, rotate, scale, shift) to resist shoulder-surfing
